# CardiLearn-X: Multimodal Cardiac Latent-State Architecture

## Purpose

CardiLearn-X is the multimodal extension of CardiLearn. Its target is not to
win a generic parameter-count contest. Its target is a validated, generalizable
representation of cardiac state from complementary observations: molecular
transcriptomics, whole-organ electrophysiology, and cellular/tissue
field-potential measurements.

## Model contract

Each modality has its own encoder and preprocessing contract. Encoders emit a
fixed-dimensional observation representation. The fusion layer then separates
shared state from modality-private information.

```text
RNA encoder   ─┐
ECG encoder   ─┼─> common projection ─> cross-modal fusion ─> Z_CARDIAC
MEA encoder   ─┘                                      └─> Z_private(modality)
```

`Z_CARDIAC` is the object evaluated as the shared cardiac state. It must not be
interpreted as causal merely because it predicts a phenotype.

## Biological axes

The representation is evaluated against independent evidence for developmental
maturation, electrophysiology, mechanical/electromechanical coupling, injury,
pathological phenotype, metabolism/stress, and regeneration. These are
validation axes, not hard-coded claims that the network has discovered those
mechanisms.

## Pairing hierarchy

1. **True paired observations:** same biological unit measured in two or more
   modalities. Highest-value data for cross-modal alignment.
2. **Biologically matched weak pairs:** correspondence defined by explicit
   study metadata such as cell line, timepoint, condition, or subject class.
   These are never represented as true pairs.
3. **Synthetic pairs:** useful for robustness experiments only; never used as
   evidence of real cross-modal correspondence.

## Training gates

### Gate 1 — Unimodal
Each encoder must beat an appropriate simple baseline on a locked held-out
cohort.

### Gate 2 — Alignment
Matched modality embeddings must show better retrieval/alignment than a
permutation/null baseline.

### Gate 3 — Fusion
The shared multimodal representation must improve a pre-specified downstream
task over the strongest single-modality model on held-out paired data.

### Gate 4 — Generalization
Evaluate on a distinct study/cohort and, where scientifically justified,
an unseen species or cell line.

### Gate 5 — Calibration and biological validity
Confidence must be calibrated. Key latent dimensions must associate with
independent biological measurements rather than only labels generated by the
same training pipeline.

## Missing modalities

The fusion core supports explicit modality availability masks and learned null
tokens. Modality dropout is used during training to prevent the model from
assuming that all three measurements are always available. Missingness is
recorded; it is not imputed and then silently treated as observed data.

## Why the shared/private split matters

RNA contains molecular information that has no direct ECG equivalent. ECG
contains timing and organ-level conduction information that is not represented
as a one-to-one molecular feature. MEA captures cellular/tissue electrical
behavior. Forcing all information into one embedding would encourage the model
to discard modality-specific signal. The architecture therefore preserves
private states while training a shared state for cross-modal biological
correspondence.

## Downstream sequence

Maturation → phenotype/injury → electromechanical coupling → confidence and
calibration → longitudinal trajectory → intervention prediction.

Intervention selection is intentionally last. A predictive latent state does
not establish causal treatment effects.
